# My Portfolio

A simple static portfolio website showcasing a resume and a small set of pages built with HTML, CSS, and JavaScript.

## Overview

This repository contains a lightweight personal portfolio site intended to be opened in a web browser. It demonstrates simple layout, styling, and client-side interactivity without a build step or server requirements.

## Files

- `index.html` — Main landing page.
- `welcome.html` — Welcome/landing page after login.
- `login.html` — Login form (demo only, no backend).
- `resume.html` — Resume/CV page.
- `style.css` — Stylesheet for the site.
- `script.js` — JavaScript for interactive behaviors.
- `README.md` — This file.

## Usage

Open `index.html` directly in your browser for a quick preview.

For a local static server (recommended to avoid file:// limitations), run one of the following from this folder:

```bash
# Python 3
python -m http.server 8000

# Node (http-server)
npx http-server -p 8000
```

Then open `http://localhost:8000` in your browser.

## Customize

Edit the HTML files to change content, update `style.css` to tweak the design, and modify `script.js` to adjust interactions.
